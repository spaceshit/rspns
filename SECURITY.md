# Security policy

Please do not report suspected vulnerabilities in public GitHub issues.

Until a dedicated security contact is published, report them privately to the
repository maintainers through GitHub's private security advisory flow. Include a
minimal reproduction, affected version, impact and any suggested mitigation.

This library analyzes untrusted response bodies. Reports concerning parser behavior,
unexpected network/file access, denial of service, unsafe output handling, or data
exposure are especially useful.
